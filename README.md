# Тюмень. Сквозь туман времени

Учебный исторический атлас для дисциплины «Основы российской государственности».
Десять глав о Тюмени, Тобольске, Ялуторовске и их окрестностях: от древних
поселений до нефтегазовых открытий XX века. Линии связывают истории, а для
реальной поездки у каждой остановки есть отдельная ссылка «Как добраться».

## Запуск на ноутбуке

Нужны Python 3 и современный браузер. Сборка и ключи сервисов не требуются.
Откройте терминал в папке проекта и выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [localhost:8000](http://localhost:8000). Остановить сервер: `Ctrl+C`.
На Windows команда может называться `py -m http.server 8000 --bind 127.0.0.1`.
Открытие самого HTML-файла также возможно, но локальный сервер предпочтительнее.
Карта, шрифты и фотографии включены в проект; внешние ссылки требуют интернета.

## Временно открыть на телефоне в той же Wi-Fi сети

Вместо предыдущей команды запустите:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Найдите локальный IP ноутбука в настройках Wi-Fi, например `192.168.1.25`.
На телефоне, подключённом к той же сети, откройте `http://192.168.1.25:8000`.
Если система попросит разрешение для входящих подключений, разрешите доступ
для домашней сети. Это временный доступ внутри локальной сети, не публикация
в интернете. Когда просмотр закончен, остановите сервер `Ctrl+C`.

## Как устроен проект

- `content/chapters.js` — тексты, даты, люди, координаты, ссылки и изображения.
- `content/geo.js` — реальная география; Leaflet рисует её без внешних тайлов.
- `assets/css/main.css` — оформление ноутбука, телефона и режима уменьшенных анимаций.
- `assets/js/app.js` — последовательность глав, переходы, финал и сохранение.
- `assets/js/map.js` — облака, география, огоньки, разнесение близких точек.
- `assets/js/config.js` — длительности переходов и показ редакционных вопросов.
- `assets/photos/` — 22 локальных изображения; `attribution.json` сохраняет
  авторство, лицензии и исходные адреса Wikimedia Commons.

Имена авторов и учебное заведение добавляются в `meta.authors` и
`meta.institution`. Сейчас эти поля пустые. Прогресс хранится в браузере
на конкретном устройстве. «К карте» не завершает главу. «Продолжить
путешествие» открывает следующую; сброс требует подтверждения.

## Фотографии и условия использования

Все используемые изображения доступны локально. Источник и лицензия
указаны в каждой главе, в окне «О проекте» и в `assets/photos/attribution.json`.
Изображения не являются автоматически частью лицензии программного кода:
при повторном использовании сохраняйте их атрибуцию и соблюдайте конкретную
лицензию. Исторические снимки и портрет помечены как общественное достояние
в Commons; остальные изображения — CC BY-SA 2.0 или 4.0.

Обновить копии с Commons:

```sh
python3 tools/download_photos.py
```

Нужен интернет. Скрипт проверяет указанные файлы, сохраняет метаданные,
не принимает изображения без распознанной свободной лицензии и сообщает
об ошибках в `assets/photos/missing.json`.

## Проверка

Повторяемый браузерный сценарий находится в `tools/browser_check.cjs`.
Сначала запустите локальный сервер, затем в другом терминале:

```sh
npm install
npx playwright install chromium
npm test
```

Для установленного Chrome на macOS можно использовать:

```sh
BROWSER_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm test
```

Проверяются главы 1–10, запрет будущих глав, прогресс после перезагрузки,
повторный просмотр, отмена и подтверждение сброса, клавиатура, кнопка
«Назад» браузера, мобильная ширина, обычные анимации и отказ загрузки фото.
Снимки сохраняются в `test-results/` и не попадают в Git.

## Статус содержания

Это работающая версия с историческими черновиками. Подтверждение
пользователем исторических материалов предусмотрено исходным заданием.
Вопросы перечислены в [docs/CONTENT_REVIEW.md](docs/CONTENT_REVIEW.md),
а полный редакционный список хранится в поле `review` каждой главы.
Перед сдачей проверьте факты и после этого отключите `SHOW_REVIEW_NOTES`.
Авторы, учебное заведение и собственные музейные фотографии пока не добавлены.
Ни публичное размещение сайта, ни слияние в основную ветку не выполнялись.
