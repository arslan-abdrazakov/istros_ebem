# Тюмень. Сквозь туман времени

Историческое путешествие по Тюменской области — учебный проект по дисциплине
«Основы российской государственности».

Пользователь открывает карту, почти полностью скрытую облаками, и шаг за шагом проходит
10 глав: от древних поселений у Андреевских озёр до нефтегазовых открытий XX века.
После каждой главы облака расходятся над следующим участком пути.

Рабочая ветка: `feature/tyumen-journey-complete`.

## Как запустить на ноутбуке

Нужен только Python 3 (на macOS и Linux он обычно уже есть; для Windows — python.org).

1. Скачайте проект: `git clone https://github.com/arslan-abdrazakov/istros_ebem.git`
   и переключитесь на ветку: `git checkout feature/tyumen-journey-complete`
   (или скачайте ZIP этой ветки на GitHub и распакуйте).
2. Откройте терминал в папке проекта и выполните:
   ```
   python3 -m http.server 8000
   ```
   (в Windows: `python -m http.server 8000`)
3. Откройте в браузере http://localhost:8000

Открыть `index.html` двойным щелчком тоже можно, но через локальный сервер надёжнее.

### Фотографии без интернета (по желанию)

По умолчанию фото загружаются с Wikimedia Commons. Чтобы сохранить их в проект:
```
python3 tools/download_photos.py
```
Скрипт скачает фото в `assets/photos/` и обновит `assets/photos/manifest.js`.
Если Wikimedia недоступна, сайт покажет вместо фото аккуратную заглушку с подписью.

## Как открыть с телефона в той же Wi-Fi сети

Это **временный доступ только внутри вашей локальной сети**, а не публикация в интернете:
сайт виден, пока ноутбук включён и запущен сервер, и только устройствам в той же сети.

1. Запустите сервер так, чтобы он был доступен другим устройствам:
   ```
   python3 -m http.server 8000 --bind 0.0.0.0
   ```
2. Узнайте адрес ноутбука в локальной сети:
   - macOS: `ipconfig getifaddr en0`
   - Windows: `ipconfig` → «IPv4-адрес»
   - Linux: `hostname -I`
3. На телефоне, подключённом к той же Wi-Fi, откройте `http://<адрес>:8000`,
   например `http://192.168.1.23:8000`.
4. Если не открывается — разрешите Python входящие подключения в брандмауэре
   или проверьте, что телефон не в гостевой сети.

Остановить сервер: `Ctrl+C` в терминале.

## Как устроен проект

```
index.html                 страница
content/chapters.js        ВСЁ содержание: тексты, даты, фото, источники, координаты
content/geo.js             данные карты (собираются скриптом, вручную не править)
assets/js/config.js        настройки: черновые пометки, длительности анимаций
assets/js/app.js           путешествие: прогресс, открытие и закрытие глав, финал
assets/js/map.js           карта, облака, огоньки, линии между главами
assets/js/util.js          типографика, фото, сохранение прогресса
assets/css/main.css        оформление
assets/fonts, assets/vendor  шрифты (OFL) и Leaflet (BSD-2)
tools/build_geo.py         сборка content/geo.js из Natural Earth и OpenStreetMap
tools/download_photos.py   скачивание фото в проект
docs/CONTENT_REVIEW.md     вопросы к проверке исторического содержания
```

### Как поменять текст, фото или порядок глав

Всё в `content/chapters.js`. Это JSON внутри JS-файла: строки в двойных кавычках,
без запятой после последнего элемента. Если ошибиться, сайт покажет сообщение
«Не удалось открыть путешествие».

- Текст главы — поля `lead`, `story`, `people`, `today`, `why`, `next`.
- Фото — поле `file`: точное имя файла на Wikimedia Commons; `author`, `license` — обязательно.
  Своё фото: положите в `assets/photos/` и укажите путь в поле `"local"`.
- Авторов проекта и учебное заведение впишите в `meta.authors` и `meta.institution`.
- Перед сдачей отключите черновые пометки: `SHOW_REVIEW_NOTES: false` в `assets/js/config.js`.

### Прогресс

Хранится в браузере (localStorage) на этом устройстве. Кнопка «Начать заново» сбрасывает его
после подтверждения.

## Источники данных и лицензии

- Фотографии — Wikimedia Commons, у каждой указаны автор и лицензия (подписи в главах и окно
  «О проекте»).
- Карта — Natural Earth (общественное достояние) и © участники OpenStreetMap (ODbL).
- Библиотека карты — Leaflet (BSD-2-Clause). Шрифты Old Standard TT и Golos Text — SIL OFL 1.1.

Тексты глав — черновики, требующие проверки. Список вопросов: `docs/CONTENT_REVIEW.md`.
