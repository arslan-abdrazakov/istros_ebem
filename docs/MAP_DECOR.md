# Дополнительные ориентиры карты

Подписи второстепенных населённых пунктов показывают географию юга Тюменской области. Они не открывают главы и не меняют маршрут. Координаты центров взяты из OpenStreetMap через страницы Mapcarta:

| Пункт | Широта | Долгота | Источник |
| --- | ---: | ---: | --- |
| Заводоуковск | 56.50929 | 66.53926 | [Mapcarta](https://mapcarta.com/15316392) |
| Ишим | 56.10920 | 69.45720 | [Mapcarta](https://mapcarta.com/15356584) |
| Ярково | 57.40559 | 67.07177 | [Mapcarta](https://mapcarta.com/15318416) |
| Нижняя Тавда | 57.67390 | 66.18274 | [Mapcarta](https://mapcarta.com/15340430) |
| Покровское | 57.23961 | 66.78756 | [Mapcarta](https://mapcarta.com/15334882) |
| Вагай | 57.93522 | 69.01259 | [Mapcarta](https://mapcarta.com/15321398) |
| Уват | 59.14288 | 68.89617 | [Mapcarta](https://mapcarta.com/15321556) |

Значки деревьев — декоративная картографическая фактура, расставленная внутри контура области. Их расположение не обозначает реальные границы леса.
