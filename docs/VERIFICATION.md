# Проверка рабочей версии

Дата: 10 октября 2026 года. Chrome на macOS, реальный браузерный сценарий
из `tools/browser_check.cjs`. Снимки экранов просмотрены вручную.

## Результат

- В начале доступна только одна точка; девять будущих глав заблокированы.
- Пройден весь маршрут 1–10 до финала, с фотографией в каждой главе.
- Кнопка «К карте» не увеличивает прогресс.
- После перезагрузки на середине пути сохраняются пять пройденных глав.
- Пройденную главу можно открыть снова; повторно завершать её не требуется.
- На полностью открытой карте все десять огоньков имеют разные экранные позиции.
- Отмена сброса сохраняет прогресс, подтверждение удаляет; перезагрузка
  после сброса открывает только первую главу.
- Enter открывает точку, Escape возвращает к карте, кнопка «Назад» браузера
  закрывает главу без завершения.
- Проверены ноутбук 1440×900, анимации при 1280×800, телефон 390×844
  и отсутствие переполнения главы на ширине 320 px.
- Обычный переход раскрывает фото из точки и открывает следующий участок.
- При имитации отказа локального и удалённого фото остаются рассказ,
  описание отсутствующего изображения и ссылка на источник.
- Ошибок JavaScript не обнаружено; десять глав и 22 локальных изображения
  проверены, файл содержания и сведения об атрибуции корректны.

## Границы проверки

Safari, Firefox, физические телефоны и поведение в разных локальных сетях
не проверялись. Исторические тексты требуют редакционной проверки;
список вопросов находится в `CONTENT_REVIEW.md`. Внешние сайты источников
и режим посещения музеев могут меняться. Сайт не размещался в интернете.
