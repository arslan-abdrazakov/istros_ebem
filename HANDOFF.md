# Состояние проекта для передачи (рабочая заметка)

Проект: сайт «Тюмень. Сквозь туман времени» для дисциплины «Основы российской государственности».
Ветка: `feature/tyumen-journey-v1`. В `main` ничего не сливалось.

## Что готово

- `content/chapters.js` — 10 глав: тексты-черновики, даты, люди, «что увидеть сегодня», «почему важно»,
  переходы между главами, фото (Wikimedia Commons с автором и лицензией), источники,
  список вопросов к проверке (`review`). Формат — JSON внутри JS-файла.
- `content/geo.js` — данные карты (реки OSM + Natural Earth), собирается `tools/build_geo.py`
  из `tools/data/rivers_osm.txt`.
- `assets/js/config.js` — настройки (показ черновых пометок, длительности анимаций).
- `assets/js/util.js` — типографика, фото с запасным вариантом, localStorage, анимации.
- `assets/js/map.js` — карта на Leaflet без тайлов: подложка, облака на canvas (привязаны к координатам),
  огоньки остановок с разнесением близких точек, дуги между главами, камера.
- `assets/js/app.js` — прогресс, открытие главы (полёт камеры → облака расходятся → фото
  раскрывается из огонька), закрытие (фото сворачивается в точку → камера отдаляется →
  открывается следующий участок), финал, сброс, окно «О проекте».
- `index.html`, шрифты (`assets/fonts`), Leaflet (`assets/vendor/leaflet`).

## Что ещё не сделано

1. `assets/css/main.css` — стили (в работе). Без него сайт работает, но выглядит «голым».
2. `tools/download_photos.py` — скачивание фото с Commons в `assets/photos/` и запись `manifest.js`.
3. README с инструкцией запуска.
4. Проверка в браузере: весь путь 1→10, перезагрузка, сброс, телефон.

## Как запустить

```
python3 -m http.server 8000
```
и открыть http://localhost:8000
